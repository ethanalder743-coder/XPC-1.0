# XPC League Website

Deploy this folder as its own Railway service.

## Railway settings

- Root Directory: `/league-website`
- Start command: Railway detects `npm start` automatically
- `BOT_API_BASE=https://xpc-10-production-95bb.up.railway.app`
- `GUILD_ID=1542189200571371530`

The public website reads live data from the bot. Use the password-protected bot dashboard to edit teams, budgets, logos, fixtures, trophies, winners, and command availability.
